# Customer-purchase-prediction---Regression-model

This project demonstrates the implementation of a regression model from scratch to predict customer spending using the Online Retail II dataset. The dataset contains transactional data, including features like Quantity and Price, which are used to calculate the target variable, TotalPrice. The goal of the project is to predict TotalPrice based on the input features while optimizing the model using gradient descent. The code avoids the use of built-in regression libraries, instead implementing linear regression step by step, including weight initialization, prediction, loss computation, and weight updates using gradient descent. The final model outputs the optimized weights, bias, and Mean Squared Error (MSE) to evaluate performance.
